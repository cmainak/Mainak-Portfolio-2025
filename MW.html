01

Discover: Exploring User Needs

Research Methodology

01 Participants 20 participants (students and early-career specialists, ages 22–35) sourced through professional Slacks and networks. All relied heavily on digital tools.
02 Methods Structured scaling surveys (Google Forms), in-depth narrative interviews (Zoom), and competitive profiling.

Key Insights

Insight 01

Overlapping Tasks

"My work, studies, and personal stuff all clash."

Target: streamline unified processing and simplified task entry.

Insight 02

Fragmented Tools

"I switch between Google Calendar, Notion, and To Do."

Target: centralize systems to lower cognitive friction.

Insight 03

Motivation Drops

"I lose track when I don't see progress or rewards."

Target: dynamic dashboards with visible progress states.

Insight 04

Poor Prioritization

"I don't know where to start when I'm overwhelmed."

Target: assistive interfaces for adaptive task distribution.

Competitive Audit

Todoist

Pros: Solid list structures, fast multi-task edits.
Cons: Complex settings, priority flags buried deep.

"I lose track of what matters because the layout feels too busy."

Habitica

Pros: Strong gamification mechanics.
Cons: High layout density overcomplicates core tasks.

"The character leveling is neat, but actual focus gets lost."

Google Calendar

Pros: Clear block visualizations.
Cons: Weak goal progression, no task frameworks.

"Perfect for meetings, but lacks support for long-term goals."

Usability Testing

Moderated sessions run on the live interactive prototype across the target cohort.

Diagnostic: AI Scheduling Task

What Broke

  • The "Plan My Day" label triggered a mismatch in expectations (67% drop-off).
  • Weak real-time visibility created processing anxiety.
  • Background AI cycles lacked clear progress notifications.
  • Missing confirmation states caused post-task tracking errors.

Fix: Renamed the feature to "Ask AI," added mandatory preview steps, and added completion confirmations to keep the user in control.
