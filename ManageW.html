01 / Discover

EXPLORING USER NEEDS!

Research Methodology

Participant Recruitment

20 participants (students and early-career professionals, ages 22–35) were recruited via LinkedIn and Slack. All participants were regular users of productivity and habit-tracking apps.

Methods Used

  • Online survey (Google Forms): Likert scale, multiple-choice, and open-ended.
  • Remote interviews (Zoom): Exploring daily routines and motivation.
  • Competitive audit: Todoist, Microsoft To Do, Habitica, and Google Calendar.

Key Findings from Survey

Theme

Overlapping Tasks

"My work, studies, and personal stuff all clash."

🎯 Opportunity: Simplify daily planning and task capture.

Theme

Fragmented Tools

"I switch between Google Calendar, Notion, and To Do."

🎯 Opportunity: Integrate workflows and reduce context switching.

Theme

Motivation Drops

"I lose track when I don't see progress or rewards."

🎯 Opportunity: Visual dashboards and gamified progress tracking.

Theme

Poor Prioritization

"I don't know where to start when I'm overwhelmed."

🎯 Opportunity: Investigate ways to support smarter scheduling.

Competitive Analysis

Todoist

Strengths: Robust task manager, recurring tasks, bulk editing.

Gaps: Setup is daunting, priorities buried.

"I forget to set priorities because capture UX is busy."

Habitica

Strengths: Gamified tracking, rewards, avatars.

Gaps: Cluttered interface, distracts from core tasks.

"I got hooked on leveling up but lost track of tasks."

Google Calendar

Strengths: Seamless scheduling, time-blocking.

Gaps: Lacks habit-tracking and prioritization features.

"Great for meetings but weak for personal goals."

Usability Testing — Task-Based Scenarios

Conducted moderated usability tests with 3 participants (student, PM, and early-career professional) on 5 core tasks.

Task 3: Ask AI (MVP)

Participant 2 completing the Plan with AI task

Critical Issues Found

  • “Plan My Day” caused expectation mismatch (67% failure rate).
  • No visible AI output created uncertainty.
  • Processing state lacked progress indicators.
  • Missing completion confirmation.

The Fix:

Renamed to "Ask AI" and added a mandatory preview and confirm step so users maintain control.

Before & After: Key Improvements

Before: Cluttered Dashboard

4-grid layout confused users on whether the focus was tasks or tracking.

→
After: Streamlined View

Simplified to two sections: Tasks and Habits, with quick visual progress bars.

Before: Heavy Interactions

Mood selectors and constant 3-dot menus created visual clutter.

→
After: Clean Lists

Introduced a top calendar widget and stripped away unnecessary elements.

04 / Deliver

FINAL DESIGNS!

CRITICAL USABILITY FIXES

  • Rename: "Plan My Day" changed to "Ask AI" to fix expectation mismatch (67% failure rate in testing).
  • Pivot: Replaced heavy "Goals" with lightweight "Habit Tracking" featuring streaks for better motivation.
  • Clean UI: Replaced cluttered 4-grid dashboard with a streamlined 2-column view (Tasks & Habits).

05 / Interact

TRY IT OUT!

Key Takeaways

AI UX Requires Transparency

Users need to see AI "thinking" and have control over outputs. Preview + confirmation steps built trust and reduced anxiety about automated scheduling decisions.

Small Changes, Big Impact

Renaming one button and adding optional date fields improved task completion by 40%. Sometimes the most impactful design decisions are the smallest ones.
