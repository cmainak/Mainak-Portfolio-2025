EXPLORING USER NEEDS!

Research Methodology

Participant Matrix

20 participants (students & early-career specialists, ages 22–35) sourced through specialized professional slacks and networks. All relied heavily on digital tools.

Execution Vector

Contextual evaluation via mixed methods: Structured scaling surveys (Google Forms), in-depth continuous narrative interviews (Zoom), and strategic competitive profiling.

Key Insights Discovery Map

Insight 01

Overlapping Tasks

"My work, studies, and personal stuff all clash."

🎯 Target: Streamline unified processing and simplified task injection mechanisms.

Insight 02

Fragmented Tools

"I switch between Google Calendar, Notion, and To Do."

🎯 Target: Centralize system structures to lower cognitive friction loops.

Insight 03

Motivation Drops

"I lose track when I don't see progress or rewards."

🎯 Target: Dynamic graphical dashboards featuring integrated reward states.

Insight 04

Poor Prioritization

"I don't know where to start when I'm overwhelmed."

🎯 Target: Investigate direct assistive interfaces for adaptive task distribution.

Competitive Audit

Todoist

Pros: Solid list architectures, swift multi-task modifications.

Cons: Complex settings overhead, priority flags buried deep.

"I lose track of what matters because layout inputs feel too busy."

Habitica

Pros: Robust structural gamification mechanisms.

Cons: High layout density that overcomplicates core production tasks.

"The character leveling system is neat, but actual focus gets lost."

Google Calendar

Pros: Excellent clear structural block visualizations.

Cons: Weak goal progression support, missing modular task frameworks.

"Perfect for meetings, but lacks support for long-term personal growth targets."

Usability Testing & Operational Validation

Moderated behavioral diagnostics run on live interactive systems across target cohorts.

Diagnostic Stream: Task 03 AI Scheduling

Continuous capture parsing user interactive loop validation.

Identified System Vulnerabilities

  • The "Plan My Day" title mechanism triggered severe expectation variance anomalies (67% operational drop-off rate).
  • Inadequate real-time data visibility indicators generated localized processing anxiety blocks.
  • Background engine operational cycles lacked clear progress state notifications.
  • Missing explicit confirmation states caused post-execution tracking errors.

Applied Architectural Pivot:

Reconfigured feature taxonomy to "Ask AI". Deployed mandatory execution preview matrices and transactional completion validation windows to maintain explicit system control loops.

Interface Refinement (Before vs After)

Legacy V1 — Unfocused Dashboard

Quadratic array spread information density too thin, blurring system priority focus maps.

→
Revised V2 — Streamlined Interface

Consolidated into primary core tracks: Direct Tasks and Active Habits with geometric progress bars.

Legacy V1 — Visual Overload

Continuous attribute configuration arrays created visual clutter and lowered processing speed.

→
Revised V2 — Focused Ingestion View

Deployed top-level horizontal calendar widgets and stripped out all low-utility elements.
