## 🧠 The Meta Case Study: Human-AI Collaboration

This repository is more than just a codebase; it is a live demonstration of modern product management and AI-Assisted Development. 

As a UX/UI Designer, I acted as the **Product Lead and Systems Architect**, defining the design tokens, accessibility constraints, and overall aesthetic vision. The frontend execution was achieved through a hybrid workflow, allowing for rapid prototyping, strict adherence to WCAG accessibility standards, and a zero-bloat architecture.

---

## ⚡ Technical Highlights

* **Zero-Framework Architecture:** Built entirely with pure Semantic HTML5, modern CSS3 (Variables, Grid, Flexbox), and Vanilla JavaScript to ensure a 100/100 Lighthouse performance score.
* **Brutalist Design Tokens:** A highly optimized CSS custom property system utilizing fluid typography (`clamp()`), a high-contrast sunset color palette, and dynamic light/dark mode glassmorphism.
* **Editorial Bento Grid:** A fully responsive, asymmetrical CSS Grid layout designed to surface flagship case studies above the fold.
* **Kinetic Typography & Motion:** Features an infinite CSS marquee and advanced scroll-linked SVG morphing via `GSAP` and `ScrollTrigger`.
* **Magnetic Micro-Interactions:** Custom mathematical DOM mapping to create frictionless, magnetic CTA buttons and parallax image layers.
