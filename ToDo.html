Project Overview

This is a fully functional, responsive web application that reimagines task management by eliminating the friction of manual data entry. Built with HTML5, Tailwind CSS, and Vanilla JS, the application leverages the Gemini API to transform unstructured natural language into organized action items.

Key features include "Smart Add," which uses AI to automatically parse dates, priorities, and categories from a single sentence, and "Task Breakdown," which intelligently decomposes complex goals into manageable sub-tasks. By replacing rigid form fields with conversational input, the app actively reduces cognitive load, allowing users to capture and organize ideas instantly.

Problem:

Traditional to-do apps function mostly as passive data-entry tools, forcing users to manually input every detail titles, categories, priorities, and deadlines turning task management into yet another task itself.

  • High Friction: The process of creating a new, well-defined task is slow and full of clicks. Users often have a thought like "buy groceries for the party this weekend" but must manually translate that into multiple form fields.
  • Poor Scannability:As lists grow, it becomes difficult to quickly identify what is important or relevant, leading to decision fatigue.
  • Rigid Structure: Re-prioritizing tasks is often clunky, requiring manual editing of "priority" numbers instead of intuitive actions.

Design Challenge

“How might we design a to-do app that leverages AI to understand user intent, reducing the friction between having a thought and organizing it?"

Problem Statement

Busy, multitasking users like Jordan need a faster and smarter way to capture and organize tasks the moment they think of them. Traditional to-do apps rely on manual data entry, which adds cognitive load instead of reducing it causing users to abandon ideas and disengage from the tool altogether.


Design Strategy - Turning Research into Action

The design strategy focused on simplifying mental effort while preserving control and flexibility.

  • Low-Friction Capture: Natural-language input that automatically interprets intent, dates, and categories, turning quick thoughts into organized tasks.
  • Guided Starting: AI-driven task breakdowns and suggested first steps that help users move from thinking to doing with minimal decision fatigue.
  • Calm Information Design: A progressive-disclosure layout that keeps the interface focused showing users only what they need, when they need it to maintain clarity and flow.
03 / Develop

Ideation & Testing

User Flow

Core User Flow: User has a thought -> Opens "Smart Add" -> Types natural sentence -> AI populates fields -> User reviews and saves.




Usability Testing

  • Participants: 5 target users (20 minutes each)
  • Tasks Observed: Adding a task with "Smart Add", and breaking down a complex task.

Three pain points emerged during testing of the initial prototype; fixes are highlighted below.

Issue — Users missed the "Smart Add"

"Oh, I just clicked the normal '+' button."

• Redesigned "Smart Add" as the primary CTA • Gave it a distinct purple color and "✨" icon • Made the traditional "Add" button secondary

Issue — "Break Down" was confusing

"What does this button do? Is it for formatting?"

• Renamed button to "✨ Break Down Task" • Added a loading spinner to show AI is working • AI now *appends* to description, not replaces

Issue — AI auto-saved wrong info

"It set the date wrong and saved it before I could check."

• AI now *populates* the main task form, it does not save • User gets a 1-second review of the populated fields • User must click "Save" to confirm the AI's work

04 / Deliver

Final Design Solutions

Final Design Solutions

  • Smart Add: A primary CTA that opens a modal, parsing natural language into a structured task using the Gemini API's JSON mode.
  • Task Breakdown: An AI-powered button that analyzes a complex task title and generates a checklist of sub-tasks in the description.
  • Full CRUD & Filters: A complete and responsive to-do app with search, filters, dark mode, and drag-and-drop reordering.
  • Error Handling: Non-blocking notifications and loading spinners provide clear feedback during AI interactions.

Results & Impact

Lessons Learned

Time-to-Task

Hypothesized 75% reduction in the average time it takes for a user to create a new, fully-detailed task using "Smart Add" vs. manual entry.

Task Completion

Hypothesized 30% increase in task completion for "complex" tasks (tasks with 3+ sub-steps) due to the "Task Breakdown" feature.

Reflection

This project reinforced that the best AI is "invisible" AI. The magic isn't the AI itself; it's how it's used to solve a human problem. The "Smart Add" feature is powerful not because it's complex, but because it makes the user's life *simpler*.

I learned that prompt engineering is a core UX skill. Designing the system prompt for the Gemini API was a crucial design task. Carefully defining the desired JSON output was essential to getting reliable, useful results for the user.
