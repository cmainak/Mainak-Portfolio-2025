WEB AUDIO & FRONT-END DEVELOPMENT

Khoai Listening Room

An open-air digital archive bringing Rabindra Sangeet to life through native HTML5 audio and a glassmorphism UI.

01. The Inspiration

Khoai is a small digital listening room inspired by the open-air spirit of Shantiniketan. The goal was to create a web player that didn't feel like a standard clinical streaming app, but rather a space that honors the cultural weight of Rabindra Sangeet.

Core Tech

HTML5 Audio API

Visual Style

Dark Glassmorphism

02. Architecture & UI

The interface leverages heavily layered CSS backgrounds and SVG turbulence filters to create a tactile, grainy texture. To keep performance high while delivering a premium feel, the application uses native JavaScript to handle state management without the overhead of heavy frameworks.

Key Design Decisions:
  • Contextual Awareness: Fetching live time via the Intl.DateTimeFormat API to show localized Shantiniketan time.
  • Thematic Playlists: Organizing tracks by Parjaay (themes like Nature, Love, Worship) using a lightweight JSON structure.
  • Tactile Interactions: Custom-built seek bars and spinning vinyl CSS animations hooked into the audio object's `timeupdate` events.
